# LaRel — Digital Studio Website

A responsive, single-page agency portfolio for LaRel. Built with semantic HTML, CSS and vanilla JavaScript. No build step or dependency installation is required.

## Run locally

Open `index.html` in a browser, or serve the folder with any static server, for example:

```bash
npx serve .
```

## Deploy

This is a static site and can be deployed to Vercel with the project root set to this directory. No environment variables are needed.

## Before the public launch

- Replace the four clearly labelled concept projects with real client work when available.
- Add LaRel's exact Instagram profile URL once confirmed.
- Confirm the contact number and WhatsApp destination.
- Add a custom domain and social preview image when ready.

## Stack

- HTML5
- CSS3 (responsive layouts, motion, CSS 3D effects)
- Vanilla JavaScript (mobile navigation and scroll reveals)
